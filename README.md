# Digital FIR Filing System

## Overview

The Digital FIR Filing System is a web-based application developed to simplify and digitize the First Information Report (FIR) registration process.

The system enables citizens to submit complaints online, track FIR status, and communicate efficiently with law enforcement authorities. It reduces paperwork, improves transparency, and enhances accessibility.

## Features

### Citizen Module
- FIR Registration
- FIR Status Tracking
- Complaint Management
- User Authentication

### Police Module
- Review FIR Requests
- Approve or Reject Complaints
- Update FIR Status
- Manage Records

### Admin Module
- User Management
- Police Station Management
- System Monitoring
